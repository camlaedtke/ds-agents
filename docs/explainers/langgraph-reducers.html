Reducers

The rule LangGraph uses to merge a node’s return value into PipelineState. Traced through one run on tests/fixtures/toy/.

The one sentence

Read this once, then stop reading and press Next below.

A node never hands back the whole state. It hands back a small dict of only the keys it changed. LangGraph then merges that dict in, one key at a time — and each key has its own merge rule. That rule is the reducer.

Annotated[list[NodeEvent], operator.add]

Rule: append. The new list is concatenated onto what is already there.

list[NodeEvent]

Rule: replace, the default when you write nothing. The new list becomes the value. Everything before it is gone.
